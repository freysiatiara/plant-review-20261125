# One Star, Written in Sap

A one-line, one-star review written by a houseplant about its human owner — for the make.fun bounty [One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4).

[![](https://make.fun/badge/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4/freysiatiara/plant-review-20261125/rank.svg)](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)
[![](https://make.fun/badge/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4/freysiatiara/plant-review-20261125/reward.svg)](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)

`main.py` (stdlib only) writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`): a single line, 155 characters, no trailing
newline, mode 0644.

> One star. He waters me with ice cubes, moves me six times a week 'for the light', and calls me low-maintenance. I'm not a plant, I'm a hostage with leaves.
